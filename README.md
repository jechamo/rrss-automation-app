# RRSS — App de Automatización de Contenido para Redes Sociales

App **web local** que funciona como pipeline de automatización para analizar appwebs y
generar contenido para RRSS (análisis de negocio, competencia, oportunidades, scraping de
virales del nicho y generación de vídeo).

> Proyecto desarrollado en modo **SDD (Spec-Driven Development)**: primero se cierran los
> documentos de Requisitos → Diseño → Arquitectura, y luego se implementa requisito a requisito.
