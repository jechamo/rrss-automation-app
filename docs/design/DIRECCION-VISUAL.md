## Necesidad de interfaz

Aplica a la bandeja de contenido, el carrusel y el asistente local. La spec 001 exige una única
pieza activa, estado perceptible además del color, foco conservado, controles accesibles, reducción
de movimiento y seis estados de interfaz. El instalador conserva un recorrido lineal con una sola
conclusión y consentimientos separados para efectos sensibles.

## Decisión aprobada

Se conserva el lenguaje visual existente de RRSS Studio y se corrige la coherencia entre carrusel,
detalle y lista sin introducir otro sistema visual. Los componentes, estados, microcopy y criterios
de accesibilidad aprobados están definidos en `design.md`; este documento registra su aprobación
global y no crea requisitos adicionales.
