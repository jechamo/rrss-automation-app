# Guía para definir la dirección visual

> Esta guía ayuda a decidir; no describe la identidad visual vigente del proyecto.

1. Reúne referencias y restricciones de marca, accesibilidad y plataforma.
2. Propón direcciones visuales realmente distintas y explica sus tradeoffs.
3. Define tokens: color, tipografía, espaciado, radio, elevación y movimiento.
4. Diseña flujo feliz, errores, vacío, carga, éxito y permisos para cada pantalla.
5. Incluye al menos un elemento con carácter por pantalla sin sacrificar claridad.
6. Verifica contraste, teclado, foco, reducción de movimiento y lectura por tecnologías de apoyo.
7. Registra la aprobación humana en `DIRECCION-VISUAL.md` y enlázala desde la spec.
